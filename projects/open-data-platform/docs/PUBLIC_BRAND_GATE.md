# Public brand gate

`Databasis` is an internal/project working name only until a public company/product-family name is independently cleared.

Current external checks found active commercial use of the name and an already-registered `databasis.io` domain. This is enough to prevent us from treating it as a cleared launch brand; it is not itself a trademark opinion.

The customer-facing site therefore remains brand-neutral.

Before production deployment, checkout, invoices, SEO, or data-marketplace listings are tied to a public name:

1. choose a small shortlist of candidate names;
2. check obvious current commercial/domain conflicts;
3. obtain appropriate legal/trademark clearance for the intended markets/classes where warranted;
4. only then replace the brand-neutral site copy and bind external provider accounts to that name.

This gate does not block product-led buyer validation for `Global Research Organization History`.
